# 追記メモの置き場

本の内容紹介は出版社が openBD に登録した公式文をそのまま出しているので、**記事を書かなくても
サイトは成り立つ**。ここは「この本だけ補足を足したい」ときに使う任意の置き場。

## 書き方

`data/articles/<ISBN13>.md` というファイル名で置く（例: `data/articles/9784873119038.md`）。
本のページの内容紹介・目次の下に「編集部のメモ」として差し込まれる。

```markdown
# 見出し（任意。1 行目が # なら見出しとして使われる）

段落。**強調**、*斜体*、[リンク](https://example.com/) が使える。

- 箇条書き
- も使える

## 中見出し
```

対応しているのは見出し・段落・箇条書き・引用・リンク・強調だけ（外部ライブラリを
増やさないため、`shinkan/articles.py` の簡単な変換を使っている）。

## 書く対象を探す

```powershell
.\.venv\Scripts\python -m shinkan pending --limit 30
```

発売日が新しい順に、まだメモの無い本が出る。
