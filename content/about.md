# このサイトについて

新刊ウォッチは、**直近 90 日に発売された本**と**これから 60 日以内に発売される本**を、
ジャンル・出版社・著者ごとに整理して毎朝自動で更新している個人運営のサイトです。

## データの出どころ

書誌データはすべて [openBD](https://openbd.jp/)（版元ドットコムとカーリルが共同運営する、
書誌情報・書影の無償提供サービス）の公開 API から取得しています。

- 書名・著者・出版社・発売日・価格・ページ数・Cコード
- 内容紹介・目次（出版社が登録した文章です。このサイトが書いたものではありません）
- 書影（各出版社が提供しているものです）

内容紹介と書影の権利は各出版社にあります。引用の範囲を超える利用はしていません。
掲載の取り下げをご希望の出版社の方は、openBD 側のデータを更新していただくか、
GitHub の Issue でお知らせください。

## 更新のしくみ

毎朝 6 時（日本時間）に GitHub Actions が動き、openBD の収録 ISBN 一覧（約 190 万件）と
前回の一覧を突き合わせて、増えた分の書誌を取得します。あわせて、手元にある「これから発売・
出たばかり」の本も取り直しているので、あとから書影や内容紹介が登録された本にも反映されます。

発売日が上の期間から外れた本は一覧から消えますが、ページ自体は残します
（リンク切れを作らないためです）。

## 購入リンクについて

各本のページにある Amazon・楽天ブックス・honto・紀伊國屋書店へのリンクは、
ISBN で各書店を検索するリンクです。アフィリエイトプログラムを利用する場合があります。
在庫・価格・発売日は書店側のページでご確認ください。

## 免責

発売日・価格・内容は変更されることがあります。掲載内容の正確性について保証はできません。
このサイトの情報によって生じた損害について、運営者は責任を負いかねます。
